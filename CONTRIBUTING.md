# Contributing to Clance

Thanks for your interest in improving Clance.

## How to contribute

1. Fork the repository and create a branch from `main`.
2. Make your change. Run `npm run build` to check that it compiles, and
   `npm start` to try it.
3. Open a pull request against `main` that explains what it changes and why.

Every pull request needs the maintainer's approval before it can be merged.
For larger changes, open an issue first so we can agree on the approach.

## Project docs

`docs/` holds the requirements, background and design. If your change
affects them, update the relevant doc in the same pull request.

## Security issues

Don't open a public issue for a vulnerability. See [SECURITY.md](SECURITY.md).

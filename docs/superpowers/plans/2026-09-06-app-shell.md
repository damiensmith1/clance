# App Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a persistent main application window to Clance — sidebar
navigation between three placeholder sections (Chats, Skills & Plugins,
Settings), a permanent Dock icon, and a Preact+htm UI layer — laying the
shell that later specs (auth, chat history, settings, extensibility UI)
build real content into.

**Architecture:** Same Electron process as the existing popup. A new
`mainWindow.ts` (parallel to `popupWindow.ts`) manages a singleton
`BrowserWindow` with native traffic lights (`titleBarStyle: "hiddenInset"`)
and sidebar vibrancy, reachable via the Dock icon and a new tray menu item.
Its renderer uses Preact + htm (vendored locally, no CDN, no bundler) for
a small hand-rolled section switcher — no router library.

**Tech Stack:** Electron (TypeScript, main process) + vanilla ES modules
with Preact/htm (renderer, no build step) — matches the existing popup's
stack exactly, just with Preact added for the larger UI surface.

**Spec:** `docs/superpowers/specs/2026-09-06-app-shell-design.md`

## Global Constraints

- No CDN script tags anywhere — every dependency the renderer loads must
  be a locally vendored file, per the project's local-first principle (the
  only network call is the Claude API request itself).
- No bundler, no JSX transform step — all renderer code ships as plain
  `<script type="module">` files loaded directly by Chromium.
- `tsconfig.json` has `rootDir: "src"`, emits to `dist/`, and does not set
  `allowJs` — `.html`/`.css`/`.js` files under `src/` are never compiled by
  `tsc`; they're copied to `dist/` by the `build` npm script's `cp`
  commands, exactly like the existing `src/popup/popup.js` /
  `markdown.js` today.
- This project has no test framework installed. Verification throughout
  this plan is: (a) `npm run build` compiles cleanly, and (b) launching
  the built app and checking `stdout`/`stderr` for errors, matching how
  every prior feature in this codebase was verified.

- [ ] **Step 4: Write the main window module**

Create `src/main/mainWindow.ts`:

```ts
import { BrowserWindow } from "electron";
import { join } from "path";

let mainWindow: BrowserWindow | null = null;

function createMainWindow(): BrowserWindow {
  const win = new BrowserWindow({
    width: 960,
    height: 640,
    minWidth: 720,
    minHeight: 480,
    titleBarStyle: "hiddenInset",
    vibrancy: "sidebar",
    visualEffectState: "active",
    webPreferences: {
      preload: join(__dirname, "../preload/mainWindow.js"),
      contextIsolation: true,
      nodeIntegration: false,
    },
  });

  win.loadFile(join(__dirname, "../mainWindow/index.html"));
  win.on("closed", () => {
    mainWindow = null;
  });

  return win;
}

export function openMainWindow(): void {
  if (!mainWindow || mainWindow.isDestroyed()) {
    mainWindow = createMainWindow();
    return;
  }

  mainWindow.show();
  mainWindow.focus();
}
```

Unlike `toggleClancePopup` (which hides on a second call), `openMainWindow`
always ends with the window shown and focused — clicking the Dock icon or
the tray item should never *close* the main window.

- [ ] **Step 5: Add the new tray menu item**

In `src/main/tray.ts`, change the signature and template:

```ts
import { Tray, Menu, app, nativeImage } from "electron";

export function createTray(onTogglePopup: () => void, onOpenMainWindow: () => void): Tray {
  // No app icon asset yet — empty image + a text title renders as a plain
  // menu-bar label until real artwork lands.
  const tray = new Tray(nativeImage.createEmpty());
  tray.setTitle("Clance");
  tray.setToolTip("Clance");

  const menu = Menu.buildFromTemplate([
    { label: "Open Clance", click: onTogglePopup },
    { label: "Open Dashboard", click: onOpenMainWindow },
    { type: "separator" },
    { label: "Quit", click: () => app.quit() },
  ]);
  tray.setContextMenu(menu);

  return tray;
}
```

("Open Dashboard" is the concrete label for the main-window tray entry,
distinct from the existing "Open Clance" popup-toggle entry.)

- [ ] **Step 3: Write the root app component with sidebar navigation**

Create `src/mainWindow/app.js`:

```js
import { h, html, render, useState } from "../shared/vendor/preact-htm-standalone.module.js";
import { ChatsSection } from "./sections/ChatsSection.js";
import { SkillsSection } from "./sections/SkillsSection.js";
import { SettingsSection } from "./sections/SettingsSection.js";

const SECTIONS = {
  chats: { label: "Chats", Component: ChatsSection },
  skills: { label: "Skills & Plugins", Component: SkillsSection },
  settings: { label: "Settings", Component: SettingsSection },
};

function App() {
  const [sectionId, setSectionId] = useState("chats");
  const ActiveSection = SECTIONS[sectionId].Component;

  return html`
    <div class="shell">
      <nav class="sidebar">
        ${Object.entries(SECTIONS).map(
          ([id, { label }]) => html`
            <button
              class=${id === sectionId ? "active" : ""}
              onClick=${() => setSectionId(id)}
            >
              ${label}
            </button>
          `
        )}
      </nav>
      <main class="content">
        <${ActiveSection} />
      </main>
    </div>
  `;
}

render(html`<${App} />`, document.getElementById("root"));
```
